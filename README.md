## 🕹️ How to Play
1. **Choose Level**: Select your difficulty level (Easy, Medium, Hard) to set the time limit.
2. **Start Game**: Click the "Start Playing" button to begin.
3. **Typing**: A random word will appear; you must type it in the input field before the countdown ends.
4. **Score**: Each correct word increases your score and generates a new word.
5. **Win Condition**: Reach the maximum score by typing all words correctly within the time limit!

## ✨ Features
* **Difficulty Levels**: Dynamic time adjustment based on the selected level (Easy, Medium, Hard).
* **Random Word Generator**: A vast library of words to ensure a new experience every time.
* **Real-time Feedback**: Countdown timer and live score tracking.
* **Interactive UI**: Smooth animations and focus management for the input field.
* **Data Persistence**: Uses JavaScript logic to manage word arrays and game states.

## 🛠️ Technologies Used
* **HTML5**: For structured semantic content.
* **CSS3**: For custom styling, layout, and responsive design.
* **JavaScript (ES6)**: For core game logic, timers, array handling, and DOM manipulation.

## 📚 Learning Outcomes
This project was built to reinforce key JavaScript concepts, including:
* **Asynchronous Logic**: Managing intervals and countdown timers.
* **Array Methods**: Handling and filtering word lists.
* **Event Handling**: Capturing user input and button clicks.
* **DOM Manipulation**: Updating the UI dynamically based on game progress.
* **Logic Implementation**: Managing game states (Start, Playing, Game Over).
