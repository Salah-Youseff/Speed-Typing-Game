## 🕹️ How to Play
1. The game randomly selects a hidden word.
2. Click on letters to guess the word.
3. Each wrong guess increases the hangman drawing.
4. You have limited attempts to guess correctly.
5. Win by guessing the word before the drawing is complete!
Letters Button: Choose The Guessing Letter From Those Button Letters.
Win Condition: Guess the word correctly before the drawing is complete.
Lose Condition: If you fail to guess the word and the drawing is complete, the game ends.
